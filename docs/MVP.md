# First Settlement MVP

> **HISTORICAL MVP (superseded):** The five-citizen three-Minecraft-day starter settlement described below is no longer the first-public-demo acceptance gate. The [authoritative charter](https://github.com/ManpreetS2/Minecraft-Ai-Civilization/blob/main/project.md) instead requires an independent 1v1 GPT/Claude technical trial, followed by 2v2 / 60 minutes in a natural world with empty inventories and no human-built starting village. Preserve this file as design history; see [current engineering status](CURRENT_STATUS_2026-11-01.md).


## Goal

Five citizens — Atlas, Maya, Theo, Ava, Kai — enter a shared Paper 1.21.11 world and autonomously attempt to survive together for at least three Minecraft days.

A messy village is acceptable. A fake village is not.

## Exit criteria

Evidence of:

- five persistent identities
- five working physical bot clients
- verified skills
- survival logic
- shared settlement resources
- work specialization
- shared shelter
- action recovery
- persistent memory
- relationships
- meaningful conversation
- high-level LLM decisions (or an honest skipped-LLM path if no local model is available)
- structured event history
- observer dashboard
- restart persistence
- multi-day autonomous simulation

## Out of scope until MVP works

Families, children, aging, generations, religion, large economy, government, elections, taxes, protests, war, multiple cities, 100–1000 agents, population LOD.

## Honest failure

Individual citizens may die. Tasks may fail. A bad civilization outcome still counts if the simulation operated autonomously and reported what happened.
